Decision-receipt API · base https://szlholdings-a11oy.hf.space

API Reference

Predictable REST. JSON in, JSON out, standard HTTP codes. The receipt primitive is a DSSE envelope signed with ECDSA-P256-SHA256 — verifiable with cosign verify-blob or the /khipu/verify endpoint. No API key needed for the demo surface.

Under 5 minutes, no key: sign a decision in the runner on the right →, get a DSSE envelope back, then verify it. Or from your terminal:
curl -s https://szlholdings-a11oy.hf.space/khipu/sign -H 'Content-Type: application/json' -d '{"payload":{"decision":"allow","subject":"demo-001"}}'

Authentication

The public demo endpoints on this page require no API key — they are rate-limited but open, so you can verify the substrate before signing up. Commercial usage is metered with keys issued by the customer portal; pass the key as Authorization: Bearer <key> when you have one. Responses follow the { data, error } shape: a non-2xx never throws, it returns an error object with the status and the gate reasons.

POST /khipu/sign LIVE

Sign a JSON payload into a DSSE envelope. This is your decision receipt: a base64 payload, a payloadType, and an ECDSA-P256-SHA256 signatures array. The server stamps the live doctrine numbers and an issued_at.

payloadobjectAny JSON you want notarized — the decision, subject, actor, and context.
# request body
{ "payload": { "decision": "allow", "subject": "demo-001", "actor": "you" } }

Try it live in the runner on the right. →

POST /khipu/verify LIVE

Verify a DSSE envelope. Returns verified, keyid_match, and the recomputed pae_digest. Flip a byte in the payload and verification fails — that is the whole point.

# response
{ "verified": true, "keyid_match": true, "pae_digest": "cafff73e…" }
GET /khipu/pubkey LIVE

The published cosign public key (PEM), its fingerprint_sha256, keyid, and curve. Verify receipts offline against this key — zero round-trip, zero trust in this server.

POST /api/a11oy/v1/govern/infer LIVE

Governed inference: model routing + Λ-gate + a split-conformal coverage block + a signed receipt. Returns decision (allow/block), an answer, a governance block (Λ advisory, capped ≤ 0.99 — advisory, never a theorem), and the doctrine block.

promptstringThe request to govern and answer.
{ "prompt": "summarize the incident report" }
GET /api/a11oy/v1/mcp/tools LIVE

The canonical live MCP surface: a JSON catalog of governed tools (several today, served live). Invoke one with POST /api/a11oy/v1/mcp/call. The Streamable-HTTP JSON-RPC transport at /mcp/ is ROADMAP — use this REST surface today.

Errors

Standard HTTP semantics: 200 success, 400 malformed, 403 blocked by the policy gate (body includes reasons), 404 unknown route, 429 quota exceeded, 5xx server error. Governed responses carry a signed (or honestly UNSIGNED) receipt where applicable.
