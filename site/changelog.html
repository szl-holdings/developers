2026-06-30dev surface v1

You can now sign and verify a decision receipt in your browser — no SDK, no key

The new developer surface ships a Stripe-style 3-column API reference with a live runner built into the page. Paste a decision, click sign, get a real DSSE envelope back from the production endpoint, then verify it — typically in under a minute.

  • Inline runner calls POST /khipu/sign then POST /khipu/verify against the live Space, cross-origin, with optimistic "signing…" feedback.
  • Every fetch uses a { data, error } wrapper — a non-2xx never throws, it shows you the status and the gate reasons.
  • Copy-paste curl for the same calls, so the page and your terminal stay in sync.

2026-06-30status v1

You can see exactly what's degraded — concrete impact, never "service issues"

The new public status page polls each component live and tells you the specific capability affected and by how much, e.g. "signing is responding but slow (~2.8s)" instead of a vague banner.

  • Four components probed live: command platform (/healthz), signing (/khipu/sign), the public key (/khipu/pubkey), and the MCP catalog.
  • Signing health is a real signing probe, not just a ping — it confirms a valid DSSE envelope comes back.
  • Honest by design: the uptime log starts at deploy. We do not fabricate historical uptime.
